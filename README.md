# Síntesis de Redes Activas

En este repositorio se encuentran los circuitos propuestos con desarrollo de cálculos, simulaciones y mediciones de los mismos.

Se implementan herramientas tales como:

- Python para scripts de cálculo (simbólico y numérico).
- Simulación en LTSpice.

Además se agrega un tutorial de Python aplicado a cálculo de circuitos analógicos.
